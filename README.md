# Excel Lookup & Error Handling Functions – Practical Exercises

## 📌 About This Repository

This repository showcases my practical learning and hands-on experience with **Microsoft Excel Lookup and Error Handling Functions**, focusing on data retrieval, searching, matching, and handling formula errors.

The exercises are designed using practical datasets and scenario-based questions to strengthen Excel problem-solving skills and improve data analysis efficiency.

## 🎯 Topics Covered

### 1. Lookup Functions
- VLOOKUP – Vertical data lookup.
- HLOOKUP – Horizontal data lookup.
- XLOOKUP – Advanced data searching and retrieval.
- LOOKUP – Searching and retrieving matching values.
- INDEX & MATCH – Flexible data lookup and matching.

### 2. Error Handling Functions
- IFERROR – Handles errors in Excel formulas.
- IFNA – Handles #N/A errors.
- ISERROR – Checks whether a formula returns an error.
- ISNA – Identifies #N/A errors.
- IF – Applies logical conditions to manage results.
